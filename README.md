# CYP direct inhibition：局部结构–药效团与计数–拓扑双视角 LightGBM

四个独立 CYP 回归任务（CYP1A2、CYP2C9、CYP2D6、CYP3A4），分别预测 pIC50。每任务使用两个固定参数模型，其预测以 1:1 平均。仓库包含 8 个全量训练后的 LightGBM 文本模型，可直接推理；不包含训练数据、盲测输入或预测结果。

本文将两个分支分别称为**局部结构–药效团分支**（代码及模型文件中为 `F1`）和**计数–拓扑分支**（代码及模型文件中为 `F3`）。前者组合二进制局部结构、Avalon 和 ErG；后者组合局部结构计数、MACCS 和 AtomPair。

## 代码和模型

- `predict.py`：从 SMILES 计算特征、加载模型并输出预测。
- `train.py`：对外部提供的训练 CSV 以固定参数重新训练 8 个模型；输出到新的空目录，避免覆盖已有权重。新模型如要用于推理，将输出目录作为 `models/` 替换（注意备份原模型）。
- `config.json`：训练参数、种子和特征方案；`models/descriptor_names.json` 冻结 RDKit 描述符顺序。
- 局部结构–药效团分支特征：Morgan radius 2（2048 位）、Avalon（1024 位）、ErG（315 维）、RDKit 2D。
- 计数–拓扑分支特征：Morgan count radius 2（2048 维）、MACCS（167 位）、AtomPair（2048 位）、RDKit 2D。此处列出的是实际拼接顺序。

Morgan 未启用手性；非有限特征置零。目标函数为 L1，四任务分别仅使用各自有标签的训练数据。训练参数源自 [ADMET-EvO](https://github.com/OTeam-AI4S/ADMET-EvO)，用于 CYP 的迁移实验，并非其 PPBR 原任务效果。

## 模型原理与设计原因

### 从分子结构到 pIC50

输入 SMILES 首先由 RDKit 解析为分子图，然后分别转换为两组固定长度的特征。对每种 CYP，各自训练一个 局部结构–药效团 LightGBM 和一个 计数–拓扑 LightGBM，共 8 个回归模型。LightGBM 通过逐步添加决策树，学习分子特征与 pIC50 之间可能存在的非线性关系和特征交互；训练时使用绝对误差目标（L1）。每个 CYP 只使用该任务具有有效标签的分子，缺失标签不会被当作零。

对同一个分子和 CYP，最终预测为：

```text
预测 pIC50 = 0.5 × 局部结构–药效团模型预测 + 0.5 × 计数–拓扑模型预测
```

pIC50 是 IC50 以 mol/L 为单位时的负十进制对数；数值越大，表示达到半数抑制所需的浓度越低。输出是连续预测值，不能直接当作实验测量值。

### 两条化学特征分支具体是什么

局部结构–药效团分支和计数–拓扑分支是两套**分子特征组合**：对同一个 SMILES，分别计算各自的特征块，再按下列顺序拼接成模型输入。它们不是 CYP 的名称，也不是两个独立数据集。两套特征都只由分子结构计算，随后各自输入对应的 LightGBM。

| 分支 | 实际拼接顺序 | 各特征块维度 | 总维度 |
| --- | --- | --- | ---: |
| **局部结构–药效团分支** | Morgan 二进制指纹 → Avalon 指纹 → ErG 指纹 → RDKit 2D 描述符 | 2048 + 1024 + 315 + 217 | **3604** |
| **计数–拓扑分支** | Morgan count 指纹 → MACCS 指纹 → AtomPair 指纹 → RDKit 2D 描述符 | 2048 + 167 + 2048 + 217 | **4480** |

其中，局部结构–药效团分支的 Morgan 使用 radius 2，以二进制位表示局部结构是否出现；计数–拓扑分支的 Morgan count 同样使用 radius 2，以计数表示局部结构出现的次数。局部结构–药效团分支进一步结合 Avalon 和 ErG；计数–拓扑分支则结合 MACCS 和 AtomPair。两条分支都包含相同的 RDKit 2D 描述符，提供整体理化性质信息。

上述 217 个 RDKit 2D 描述符及总维度对应本项目冻结的 RDKit 2025.9.3 环境；描述符名称和顺序保存在 `models/descriptor_names.json`，推理时会检查。计数–拓扑分支的 MACCS 在 AtomPair 之前，是本实现的实际拼接顺序，推理时必须保持一致。

### 为什么使用多种分子表示

CYP 抑制与分子的局部化学环境、官能团、原子之间的连接关系以及整体理化性质等因素有关。单一指纹只能从某些角度描述结构，因此本方案把互补的分子表示组合起来，让模型有机会同时利用局部结构、拓扑关系和整体性质：

| 表示 | 提供的信息 | 在本方案中的作用 |
| --- | --- | --- |
| Morgan 二进制指纹 | 以原子邻域为中心的局部结构是否出现 | 为局部结构–药效团分支提供局部化学环境和子结构模式 |
| Morgan count 指纹 | 局部结构出现的次数 | 为计数–拓扑分支补充重复子结构的数量信息 |
| Avalon 指纹 | 不同于 Morgan 的结构编码 | 为局部结构–药效团分支提供另一种子结构视角 |
| ErG | 经约简后的药效团特征及其拓扑关系 | 为局部结构–药效团分支提供较抽象的官能团与空间相关信息 |
| MACCS | 一组预定义结构键是否存在 | 为计数–拓扑分支提供可解释的结构片段提示 |
| AtomPair | 原子类型及其拓扑距离的组合 | 为计数–拓扑分支补充分子内原子之间的连接和距离关系 |
| RDKit 2D 描述符 | 分子量、极性、脂溶性相关指标等整体性质 | 为两个分支提供与分子整体性质相关的连续特征 |

这些表示并不直接测量分子与 CYP 的结合构象或抑制机制，而是从二维结构中提取可能有助于预测的代理信息。它们也可能存在重叠、信息损失和指纹哈希碰撞；增加特征并不必然提高效果。当前实现的 Morgan 未启用手性，因此不能充分区分仅立体化学不同的分子。

### 为什么融合两个 LightGBM

两个分支使用不同的特征组合及固定超参数，分别从不同结构视角拟合。单个模型可能对特定表示中的结构模式过度依赖，也可能受到训练样本和模型参数的影响。若两个分支的预测误差不完全相同，对预测取平均有机会抵消部分误差，降低对某一特征视角或单个模型的依赖，使结果更稳定。

为控制模型复杂度和减少不必要的选择，两个分支采用固定树深度、叶子数、最小叶节点样本数、特征及样本采样和正则化参数；融合权重事先固定为 1:1，没有使用外层验证标签选择权重。外层按分子骨架分组，有助于检验对未见骨架的泛化，降低近似结构同时落入训练和验证侧造成的乐观偏差。

这些设计**不能保证消除过拟合或系统性偏差**：两个模型共享训练数据和部分特征，也可能共同继承数据分布、标签噪声及模型形式带来的偏差。骨架验证也不能完全代表真实盲测分布。实际五折中，融合的 MA-ST-RAE 为 0.715456，低于计数–拓扑分支的 0.720006 和局部结构–药效团分支的 0.724456；成员残差相关性约为 0.975–0.988，说明误差高度相关，互补收益有限。上述结果支持该固定融合在本次开发验证中的效果，但不保证在新数据或比赛盲测上同样改善。

## 环境与推理

使用 Python 3.11 和 `pip install -r requirements.txt`。模型在 macOS ARM64、Python 3.11.18、RDKit 2025.9.3、LightGBM 4.7.0 上训练及验证。LightGBM 可能需要平台对应的 OpenMP 运行库；不同平台应自行验证一致性。程序检查 RDKit 描述符名及顺序。

```bash
python predict.py input.csv output.csv
python train.py train.csv new_models
```

输入必须含唯一非空 `Molecule_Name` 和有效 `SMILES`。输出保留这两列及四个 `CYP*_pIC50_direct_inhibition` 列，顺序与输入一致。训练表额外需要这四个目标列，缺失标签留空；已有 pIC50 不再取对数。

## 验证结果

固定五折骨架验证，融合外折平均 MA-ST-RAE 0.715456，汇总 OOF 0.711847；计数–拓扑分支、局部结构–药效团分支分别为 0.720006、0.724456。项目 B0（RDKit + Morgan）为 0.789606。这是开发验证，不是盲测排行榜成绩。固定参数未做内层搜索；训练数据 4905 个分子，6525 个有效标签。CYP2D6 汇总 OOF ST-RAE 0.883896，MAE 0.581730。

独立推理入口在原 750 条盲测输入上与原实验输出逐值一致（最大绝对误差 0）。不发布原始输入或输出；没有盲测真值，无法计算盲测得分。现有脚本不包含五折划分和评估复现代码，分数来自原实验记录。
